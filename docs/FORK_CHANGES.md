# 本 fork 的本地研究改动

本次同步以 fork 的 `cb92401` 为基础，保留其后于原实验基线 `76a6ca5` 的上游更新。
来源为本地 AlphaMaster-demo 和 2026-11-04 WILLR 修复版实验。

## 核心代码

- 修正 WILLR_14 符号，保留 [-1, 0] 范围内的负值。
- 多股票输出采用 neutral-zero-v1：相同或仅有舍入误差的截面输出中性零，按日使用 float64 中心化及标准差；单股票分支保持原行为。
- 模型宽度、层数、头数和前馈宽度可配置，默认仍为原小模型。
- 支持策略模型与公式评估分别选择设备、CPU 线程限制、逐步指标和回调。
- 主项目不提供 step_hook 时保留默认每20步及末步保存检查点；冻结实验快照由自己的 runner 每200步保存完整状态。
- ALPHAMASTER_DEMO=1 时采用只做多信号，原生图表与共享仓位函数一致。

## 已知边界

旧标准化缺陷下的收益不能继续用于证明策略有效。最新一轮只有一个随机种子，2025年用于选择公式；2026年已被反复查看，属于回看对照。股票池按当前市值筛选，存在历史选择偏差。多股票实验仍为分数仓位研究回测，未完整实现整手、最低佣金等实际约束。

仓库包含源码、配置，以及最新小盘股实验所需的21个冻结JSON输入（股票池名单和20只股票行情，约3 MiB）。未包含行情数据库、模型权重、日志、个人配置或历史运行产物。复现历史数值仍需要匹配原环境；重新抓取当前数据会构成不同实验。
